# Spotify-dashboard
🚀 Explore an end-to-end Spotify Analytics Power BI project mapping 526bn streams. Features four optimized dashboards: overview.png (KPIs/genres), Artist &amp; Labels.png (market share/revenue), Geography.jpg (global choropleth tracking), and Social &amp; Vibes.png (social metrics/mood trends). Built with advanced DAX and dark-mode UI/UX.
